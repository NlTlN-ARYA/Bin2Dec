# Bin2Dec — Binary to Decimal Converter

A beginner-friendly Python project that converts binary numbers (base 2) into decimal numbers (base 10).

## Features

- Converts binary numbers to decimal.
- Validates input to allow only `0` and `1`.
- Handles empty input.
- Removes unnecessary whitespace at the beginning and end of input.
- Uses a custom conversion algorithm.

## How It Works

Each binary digit represents a power of 2.

For example:

`1011` = 1 × 2³ + 0 × 2² + 1 × 2¹ + 1 × 2⁰

`1011` = 8 + 0 + 2 + 1 = **11**

## Requirements

- Python 3

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   `python bin2dec.py`
